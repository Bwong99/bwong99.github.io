CPEN 321 App

A student coursework project for CPEN 321 Software Engineering at the University of British Columbia.

CPEN 321 App is an Android application built as an individual assignment for a university software engineering course. It is not a commercial product and is not distributed on the Google Play Store. It exists to demonstrate a small set of course requirements.

What the app does

  • Signs the user in with their Google account and displays the server's public IP address, the device's IP address, the server and device local times, and the signed-in user's name.
  • Displays a pixel-art image that assembles live, one cell at a time, from a stream relayed by the app's own back-end server.
  • Runs a countdown timer that reveals a procedurally generated piece of pixel art when it reaches zero.

Google sign-in

The app uses Google Sign-In through Android's Credential Manager. It requests only basic profile information — the openid, email and profile scopes — and uses it solely to display the signed-in user's first and last name on screen. The identity token is verified by the app's own back-end server against Google's public keys, and nothing is stored. See the privacy policy for details.
